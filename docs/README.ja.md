# Oclock の使い方

時計・アラーム・タイマー・天気を1画面で使えるブラウザアプリです。

## 起動

フォルダーで `python -m http.server 8787 --bind 127.0.0.1` を実行し、ブラウザで `http://localhost:8787` を開いてください。ビルドやライブラリのインストールは不要です。現在地取得には localhost または HTTPS が必要です。

## アラーム

1. 「アラームを追加」を押して、時刻と曜日を設定します。
2. 「保存」で登録します。設定変更は毎回ブラウザに自動保存されます。
3. 一覧の ON / OFF で有効状態を変更します。「編集」「削除」も一覧から操作できます。
4. 鳴動中は「音を止める」、または「5分後にもう一度」を押します。Escape キーでも停止できます。

最大10件です。曜日は少なくとも1つ選びます。OFF・削除・編集により、そのアラームの待機中スヌーズを解除します。

## タイマー

3・5・10・20・30・60・120分から選ぶと即開始します。実行中に別の時間を選ぶと、新しいタイマーに置き換わります。

- **一時停止／再開**：残り時間を保持して中断・再開します。
- **停止**：動作を終了し、残り時間を0にします。選択したプリセットは残ります。
- **リセット**：プリセットの選択も解除し、初期状態に戻します。

1時間未満は MM:SS、1時間以上は HH:MM:SS 表示です。終了時に中央のダイアログから音を止められます。タイマーにはスヌーズはありません。

## 天気・音

天気の初期地点は船橋市です。「現在地を使う」を押して位置情報を許可すると、その地点の天気を表示します。地域表示は「現在地」になります。「船橋市に戻す」で固定地点に戻せます。15分ごとに自動更新し、取得失敗時も他の機能は動作します。固定地点は `app.js` の `fixedLocation` で変更できます。

最初のクリックまたはキー操作で音を準備します。画面右上が「音は有効です」になったことを確認してください。端末の音量・消音設定によっては聞こえません。

## 保存と動作条件

- アラームだけを保存します。タイマー・スヌーズ・現在地選択は再読み込みで解除されます。
- ブラウザを閉じたり、端末がスリープしたりすると鳴動できません。ページを開き、端末を起動したまま使ってください。
- バックグラウンドでは通知が遅れることがあります。1分以内に遅延したアラームは一度だけ通知し、それ以前のアラームは通知しません。
- タイマーは終了予定時刻との差で計算し、画面が再び動作したときに終了を検知します。
- サイトデータを消すとアラームも消えます。保存に失敗した場合は一覧の下に表示します。
- 天気の取得にはインターネットが必要です。位置情報は「現在地を使う」の操作後に取得し、天気サービスに送信します。
